# Multi-Modal Deep Learning System

## Set Up

Create the virtual environment using `requirements.yml`

```python
conda env create -f requirements.yml
conda activate CSB410_final
```

Run the full system demo using `notebooks/5_application.ipynb`

To run an individual model:

- Download the corresponding datasets
- Upload the dataset to Google Drive and mount it in Colab
- Run the corresponding notebook in the `notebooks` folder

## Datasets
- [UEC Food Pix Complete](https://mm.cs.uec.ac.jp/uecfoodpix/)

- [Food 101 Images](https://www.tensorflow.org/datasets/catalog/food101)

- [Food.com Recipes and Interactions](https://www.kaggle.com/datasets/shuyangli94/food-com-recipes-and-user-interactions)
